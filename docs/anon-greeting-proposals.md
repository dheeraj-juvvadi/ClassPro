# Greeting proposals — awaiting approval

Keep the approved greeting for the first hour of each IST period: 05:00–05:59,
12:00–12:59, 17:00–17:59 and 22:00–22:59. Afterward, choose from the appropriate
pool, once per visit/time period, without changing on navigation or data sync.
The fixed greetings retain the approved name rule. Rotating greetings contain
exactly two words, without an appended name. “Still here?” is the approved style
reference. This revised pool is awaiting review and is not active in the app.

Research: Claude Code's public issue tracker documents the short personalized
“Welcome back {account name}” pattern:
https://github.com/anthropics/claude-code/issues/87219
OpenAI's published prompting guide recommends natural, conversational, playful
language and avoiding ungrounded flattery:
https://github.com/openai/openai-cookbook/blob/main/examples/gpt-5/gpt-5-2_prompting_guide.ipynb
These are original Anon proposals, not quotations from either product. The
ChatGPT personality help page returned HTTP 403 during this review.
