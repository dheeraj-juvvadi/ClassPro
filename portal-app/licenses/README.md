# UI component attribution

The login page adapts the interaction and styling of these components to the existing vanilla JavaScript app:

- React Bits SpotlightCard: https://github.com/DavidHDev/react-bits/tree/main/src/content/Components/SpotlightCard — David Haz. License retained in react-bits.txt.
- OpenSourceUI PasswordFieldInput: https://github.com/bidyut10/opensourceui/blob/main/components/inputs/password-field-input.tsx — Bidyut Kundu. MIT license retained in opensourceui.txt.

Implementation: public/login-effects.js, public/garden.css, and password field markup in public/index.html. No React runtime is required for these adaptations. Botanical SVG artwork and layout are original to this app.

Current login artwork: public/floral-screenprint.svg and public/floral-mobile.svg, original deterministic paths and distress marks generated by scripts/build-floral-art.py. The realistic museum painting and SpotlightCard effect are no longer used on the login page. The OpenSourceUI password-visibility adaptation remains.
